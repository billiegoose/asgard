# Examples

## Recordings

### Pong — Python RED2

[![Asgard Pong asciicast](https://asciinema.org/a/4O27VEiw9i3E2gjy.svg)](https://asciinema.org/a/4O27VEiw9i3E2gjy)

Replay the committed recording generated by the native Python RED2 IO runner:

```sh
asciinema play examples/media/pong.cast
```

Regenerate it with:

```sh
mise run generate-video pong --no-upload
```

### Breakout — Python RED2

[![Asgard Breakout asciicast](https://asciinema.org/a/ZA2OrmB0Mc9aAdfq.svg)](https://asciinema.org/a/ZA2OrmB0Mc9aAdfq)

Replay the committed local cast:

```sh
asciinema play examples/media/breakout.cast
```

Watch the WASM Breakout recording:

[![Asgard Breakout WASM asciicast](https://asciinema.org/a/FwTtMVlFHcivZAfA.svg)](https://asciinema.org/a/FwTtMVlFHcivZAfA)

Replay the committed local WASM cast:

```sh
asciinema play examples/media/breakout-wasm.cast
```

Regenerate and upload this recording:

```sh
mise run generate-video breakout
```
