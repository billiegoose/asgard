# PAPER

Scheme experiments related to theorem proving and compact/shared representations, dated April 1989.

## Files

- `BOYER.S` — implementation of Boyer-Moore structure sharing for theorem proving, based on their Machine Intelligence 7 paper. Includes reconstruction of shared resolvent records.
- `ORDER.S` — Order(n) theorem-proving data structures, ordered clauses, environments, unification-related utilities.
- `TEST.S` — small test clause set.

This work is separate from the core THOR/RED2 reducer, though its emphasis on compact representation, environments, sharing, and reconstruction is conceptually adjacent to Hilton's architecture work.
