# SNARL

Container directory for three closely related January-1990 C snapshots of the Version 1.0-era Head Order Reduction System.

- `SNARL/` — release-like January 11, 1990 tree.
- `EXPERIME/` — experimental sibling.
- `OPT/` — optimized-build sibling.

There are no source files directly in this directory.

The name **SNARL** appears in source comments immediately before the later `THOR/` tree. Diffs show that `THOR/` is extremely close to `SNARL/SNARL/`, with later timestamps, THOR branding/copyright additions, and a change from `LISTS.LAM` to a generalized `PRELUDE.LAM` startup file.
